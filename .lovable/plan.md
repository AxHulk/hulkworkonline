# SEO-план под целевые запросы

## Анализ запросов

Все 50 запросов разбиваются на 3 кластера:

**1. Коммерческие "сайты под ключ" (~30 запросов)**
"сделать сайт для компании", "корпоративный сайт под ключ", "разработка корпоративного портала", "стоимость сайта", "веб агентство", "лендинг под ключ" и т.д. → ведут на `/services/web-development`.

**2. Гео-запросы по продвижению (~12 запросов)**
"продвижение спб/санкт-петербург/екатеринбург/красноярск/уфа/тула/самара/саранск/барнаул/краснодар" → ведут на `/services/seo`.

**3. Гео-запросы "сайт под ключ + город" (~4 запроса)**
"сайт под ключ в москве/краснодаре", "изготовление сайта под ключ москва", "корпоративный сайт под ключ москва" → требуют отдельных гео-посадочных.

Ваши приоритетные гео: **Москва, СПб, Казань, Краснодар, Сочи, Крым** — частично совпадают со списком (Москва, СПб, Краснодар), частично нет (Казани/Сочи/Крыма в запросах нет, но добавим под ваш фокус).

## Что предлагаю сделать

### A. Гео-посадочные страницы (главный рычаг)

Создать 6 типовых страниц-двойников для каждой услуги × город. Самое весомое — для веб-разработки и SEO (ваши деньги-запросы).

```
/services/web-development/moskva
/services/web-development/spb
/services/web-development/krasnodar
/services/web-development/kazan
/services/web-development/sochi
/services/web-development/crimea

/services/seo/moskva
/services/seo/spb
/services/seo/krasnodar
/services/seo/kazan
/services/seo/sochi
/services/seo/crimea
```

Реализация: одна общая компонента-шаблон + JSON с данными по городам (название в падежах, локальные кейсы, цены, упоминание города 6–10 раз в тексте, LocalBusiness JSON-LD с `areaServed`). Контент будет на 70% общий + 30% уникальный гео-блок (упоминание района, локальных кейсов, "работаем со всей [область]").

**Это закрывает запросы**: "продвижение спб/краснодар/...", "сайт под ключ в москве", "корпоративный сайт под ключ москва", "изготовление сайтов в москве" и др.

## Технические детали

- Гео-страница: `src/pages/ServiceCityPage.tsx`, данные в `src/data/cities.ts` (склонения, координаты для LocalBusiness, локальные особенности).
- Динамический роутинг: `/services/:service/:city` с whitelist'ом, иначе → `NotFound`.
- Каноникал каждой гео-страницы — на саму себя.
- `hreflang` не нужен (только русский).
- В JSON-LD `Service.areaServed` указывать `City` с `name` и `containedInPlace` (регион).

## Чего НЕ делаю

- Не закупаю ссылки и не обещаю позиции — это вне кода.
- Не дублирую контент 1-в-1 между гео — это санкции Яндекса.
- Не ставлю плейсхолдеры в кейсах (по вашему правилу).
